# Phase 21 performance and release gates

The Core gate is intentionally parameterized: the release default is a 30-minute mixed 256 TCP / 256 UDP run, while local development may opt into a short run explicitly. Every poll status, batch accepted count, reply count, drop counter, queue peak, active-flow bound, and stop status is checked.

This repository does not claim iOS device, Jetsam, signed XCFramework, or controlled VLESS/Reality/Vision interoperability evidence until the corresponding external gate produces a manifest update.
