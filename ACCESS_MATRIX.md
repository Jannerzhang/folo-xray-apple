# Access matrix

| Role | Repository access | Merge rights | Release rights | Secret access |
| --- | --- | --- | --- | --- |
| MPL maintainer | Write | Reviewed pull requests | Approved source/artifact release | None |
| License/security reviewer | Read | Required review for license/security paths | Release veto | None |
| iOS maintainer | Read/write wrapper and build proposals | Reviewed pull requests | None by default | None |
| Release automation | Read plus artifact publication | None | Tag-bound artifact only | Short-lived release credential |
| Anonymous user | Read | None | Download public sources/artifacts | None |

Direct pushes to protected `main` are prohibited after bootstrap. Public disclosure never includes private Folo material.
