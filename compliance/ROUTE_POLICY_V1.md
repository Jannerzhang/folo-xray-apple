# RoutePolicy v1

The Rust FFI receives the versioned, non-secret routing projection generated by
the private iOS client. `schemaVersion`, `revision`, `action`, `reason` and
`provenance` remain stable fields.

The priority is:

```text
security block
> explicit proxy/direct
> DNS mapping with the active revision
> sniffed domain
> IP set
> mode/default
```

The core does not accept arbitrary host-app configuration, credentials,
subscription URLs, private Network Extension APIs, or a local proxy listener.
