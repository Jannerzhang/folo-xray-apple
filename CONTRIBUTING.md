# Contributing

- Base all upstream imports on an approved exact tag and commit; floating branches are prohibited.
- Preserve copyright headers, license texts, source URLs, commit identifiers, and acquisition hashes.
- Keep modifications as an ordered patch series or clearly reviewable commits.
- Do not mix Folo private business logic into upstream or wrapper files.
- Do not add a binary until its source, toolchain, build command, SBOM, notice, exported symbols, and SHA-256 are available.
- Release tags use `app-v<app-version>-core.<revision>` and are immutable.
- Security and licensing changes require code-owner review.
